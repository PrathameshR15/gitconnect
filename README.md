# gitconnect

A simple Python calculator with an interactive command-line interface.

## Features

| # | Operation | Function | Operands |
|---|-----------|----------|----------|
| 1 | Addition | `add(x, y)` | 2 |
| 2 | Subtraction | `subtract(x, y)` | 2 |
| 3 | Multiplication | `multiply(x, y)` | 2 |
| 4 | Division | `divide(x, y)` | 2 |
| 5 | Power | `power(x, y)` | 2 |
| 6 | Modulo | `modulo(x, y)` | 2 |
| 7 | Square | `square(x)` | 1 |
| 8 | Square Root | `square_root(x)` | 1 |
| 9 | Factorial | `factorial(n)` | 1 |
| 10 | Absolute Value | `absolute_value(x)` | 1 |

## Usage

```bash
python calculator.py
```

## Running Tests

python -m unittest test_calculator.py -v
